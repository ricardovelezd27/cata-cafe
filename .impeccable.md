## Design Context

### Users
**Who:** Q-graders, certified cuppers, and specialty coffee professionals — people who have invested years learning a precise sensory vocabulary. They operate in lab or production environments, often in time-pressured blind-tasting contexts.

**Context:** Evaluations happen under structured conditions (the SCA CVA protocol). Users have a physical cupping table in front of them, cups numbered 1–5, a printed sample sheet, and now also this app. The app must not compete with the coffee for attention.

**Job to be done:** Conduct a complete SCA CVA evaluation — descriptive intensities, affective scores, cup defect tracking — and produce a final CVA score they can trust and export. In group sessions: submit their evaluation, track group progress, and compare their scores against the aggregate.

**Primary language:** Spanish. Users are Latin American specialty coffee professionals; the UI speaks their language, literally and culturally.

---

### Brand Personality
**Three words:** Auténtico · Profesional · Refinado

- **Auténtico** — Rooted in real coffee culture. The palette, typography, and language feel like they belong in a specialty cupping lab, not a generic SaaS tool.
- **Profesional** — This is a serious tool for credentialed professionals. It doesn't condescend or over-explain. It trusts the user.
- **Refinado** — Elegant execution. Nothing superfluous. Every element earns its place. The kind of tool a Q-grader would be proud to show at a competition.

---

### Emotional Goal
**Data clarity.** Users should always know exactly where they stand — current score, evaluation progress, group submissions. There is no ambiguity about what has been saved, what is pending, or what the numbers mean. The feeling is quiet confidence: *I trust this tool completely.*

---

### Aesthetic Direction
**Reference:** Headspace + Linear — calm, spacious, intentional. Every pixel is purposeful. The UI steps back so the content (the coffee, the scores) steps forward.

**Visual tone:** Editorial precision. The typography-forward approach (Newsreader for display, Hanken Grotesk for UI) gives the interface a specialty-publication quality. Scores are displayed large, in serif numerals, because they *matter*.

**Palette:** Earthy and warm without being rustic. Forest greens (`primary-container`) anchor primary actions; warm surface tones reference parchment and roasted coffee; terracotta (`secondary`) marks energy and emphasis — never quality; `error` is clinical and reserved strictly for defects and problems.

**Anti-references:**
- NOT consumer coffee apps (Starbucks, Blue Bottle) — too lifestyle, too decorative
- NOT generic SaaS (plain Notion, spreadsheet-like dashboards) — too cold, loses craft context
- NOT illustrated / artisanal / hipster coffee shop — no illustrated coffee cups, no hand-drawn textures
- NOT clinical / medical UI — precision without sterility

**Mode:** Light mode only. The warm parchment background (#FDFBF7) is a core part of the identity.

---

### Design Principles

1. **Data speaks first.**
   Scores, section breakdowns, and submission states are always the visual hero. Typography and spacing serve data legibility above all else. Never bury a number.

2. **Trust through precision.**
   Exact values with consistent rounding, tabular numerics (Hanken Grotesk + `tabular-nums`), and unambiguous status indicators. Nothing vague, nothing estimated. If it's 83.25, show 83.25.

3. **Craft without decoration.**
   The earthy palette and serif typography reference specialty coffee craft. Achieve richness through type and color — not through illustration, texture, or ornament.

4. **Calm before complexity.**
   The SCA CVA protocol is cognitively demanding. The interface must be spacious and sequenced to protect the user's focus. One thing at a time. Collapse what isn't needed now.

5. **Spanish first, always.**
   Language, labels, units, and metaphors are rooted in Latin American specialty coffee culture. Translations exist but Spanish is the design language, not the afterthought.

### Component Library (components/ui/)

| Component | Purpose |
|---|---|
| `IntensitySlider` | 0–15 descriptive intensity, step 0.5 |
| `AffectiveBubbles` | 1–9 hedonic scale, color-coded by tier |
| `CATAPills` | Multi-select flavor/taxonomy pills with color + sub-items |
| `CupIndicators` | Per-sample cup status (uniform / non-uniform / defective) |
| `ScoreDisplay` | Final CVA score card with formula breakdown |
| `DataTable` | Generic sortable/searchable/filterable list table (desktop table ≥`md:`, mobile cards) |
| `Badge` / `StatusPill` / `ScorePill` | The only status/score pill implementations — never hand-roll pills |
| `PageHeader` | Canonical page title + description + action slot |
| `EmptyState` | Icon + heading + body + CTA for empty collections |
| `ConfirmDialog` | Destructive-action confirm on ResponsiveDialog (honest cascade copy) |
| `SearchInput` / `Select` / `FilterBar` / `Pagination` | Table/query controls |
| `OfflineBanner` | Persistent offline-status indicator during cupping (`components/offline/`) |
| `SyncConflictModal` | Resolve a draft that was submitted elsewhere while offline |
| `WelcomeModal` | First-run onboarding: role + country capture, guided first action (`components/onboarding/`) |

All components are controlled. State lives in parent (`CupClient` / Zustand).
