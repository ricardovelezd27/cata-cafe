# S6 CP-A5 — close email: link + personal summary PDF

## What changed
- `lib/closeEmail.ts`: body now links to the results page (login URL with `next`);
  attachment is only the participant summary PDF (`resumen_<slug>.pdf` /
  `summary_<slug>.pdf`). The per-recipient CVA form is attached only when
  `CLOSE_EMAIL_ATTACH_CVA=1`. The anonymous group-summary render and
  `assetsByLocale` PDF cache are gone (`GroupSummaryDocument.tsx` stays on disk).
- Report source is loaded once per recipient locale (max 2), not once per recipient.
- Pure body builder: `lib/closeEmailBody.ts` (tested in `tests/closeEmail.test.ts`);
  `siteOrigin()` / `buildResultsLoginUrl()` added to `lib/inviteUrl.ts`.
- Ledger/CONCURRENCY/already-sent skip unchanged. A throw from the summary
  model/render marks only that recipient `failed` (lastError `summary: ...`).
