# Objetivos y metodologías de cata — hoja de trabajo (Kim)

> Antes de construir "objetivos estructurados" en la app, diseñamos y probamos
> las metodologías a mano. Esta hoja se rellena fuera del software. Cada fila
> completa es un candidato a "tipo de sesión" futuro; una fila vacía es una
> señal de que todavía no sabemos lo suficiente.

## Principio

El puntaje necesita contexto. Un café puede ser excelente para un objetivo y poco
adecuado para otro. Cada sesión debería poder responder: ¿qué busco?, ¿con qué
criterio?, ¿contra qué referencia?, ¿cómo se lee el número?

## Plantilla por tipo de objetivo

Copia el bloque por cada objetivo. Ejemplos iniciales abajo.

```
### <Nombre del objetivo>
- Qué se quiere conseguir:
- Quién participa (perfil, nivel):
- Formato de cata (descriptivo / afectivo / combinado) y por qué:
- Criterio de evaluación (qué significa "bueno" aquí):
- ¿Hace falta referencia?  sí / no / por atributo
  - ¿Quién la elige?  maestro / grupo / cliente / ninguna
  - ¿Cuándo?  antes / durante / después
- Cómo debe leerse el puntaje (absoluto, relativo a la referencia, relativo al grupo):
- Qué comparación importa al final (yo vs ref / yo vs grupo / experto vs grupo / grupo A vs grupo B):
- Qué se hace con el resultado (decisión, aprendizaje, informe):
- Qué NO debe hacer la app en este objetivo:
- Ejemplo real que podemos probar a mano:
```

### Objetivo educativo — aprender a identificar perfiles
- Qué se quiere conseguir: que el alumno reconozca atributos y aprenda a evaluar *relativo* a algo.
- Referencia: sí, elegida por el maestro antes de la sesión.
- Lectura del puntaje: relativo a la referencia ("¿más o menos acidez que C?").
- Comparación final: yo vs referencia; después yo vs grupo.
- Pendiente de rellenar: …

### Objetivo de calibración — alinear evaluaciones entre catadores
- Referencia: sí (maestro). La desviación (±) del grupo es el indicador principal.
- Comparación final: yo vs grupo, maestro vs grupo.
- Pendiente: …

### Objetivo de selección — elegir el café más adecuado para un uso (espresso, filtro, compra)
- Criterio: el objetivo define qué atributos pesan más; el puntaje absoluto pierde peso.
- Referencia: sí o no (¿el café actual de la carta como referencia?).
- Pendiente: …

### Objetivo de consumidor — medir qué café gusta más a un público
- Participantes: no expertos; formato afectivo simplificado.
- Referencia: normalmente no.
- Comparación final: grupo (consumidores) vs experto/tostador.
- Pendiente: …

### Objetivo profesional — comparar la percepción de un experto con la de clientes o equipo
- Comparación final: experto vs grupo por atributo; la diferencia es el resultado, no un error.

## Preguntas abiertas para decidir después de las pruebas

1. ¿Cuándo hace falta una referencia y cuándo estorba?
2. ¿Puede haber una referencia distinta por atributo? ¿Vale la pena?
3. ¿Quién puede fijar la referencia: solo el maestro, o también un cliente/grupo?
4. ¿Cómo se representa a la vez referencia, media del grupo y mi evaluación sin confundir?
5. ¿Cómo se explica el contexto de un puntaje en una sola línea?
